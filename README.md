# Statistics_mini_project
Car Price Prediction Using Multiple Linear Regression

 Project Description

This project predicts the selling price of used cars using Multiple Linear Regression. The model uses different car characteristics such as manufacturing year, kilometres driven, mileage, engine capacity, maximum power, and number of seats.

 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

 Data Analysis

The dataset is cleaned and analyzed using:

- Missing value handling
- Duplicate checking
- Data visualization
- Correlation heatmap

 Machine Learning Model

Multiple Linear Regression

The dataset is divided into 70% training data and 30% testing data.

 Evaluation Metrics

The model is evaluated using:

- R² Score
- Adjusted R²
- RMSE
- MAE

 Objective

To develop a machine learning model that can estimate the selling price of a used car based on its features.

 Conclusion

The project demonstrates how Multiple Linear Regression can be used to estimate used-car prices from vehicle characteristics.
